# Privé — Next.js site

Next.js 16 (App Router) + React 19 + framer-motion. No Framer runtime: every section is a native component.

```bash
npm install
npm run dev
```

## Pages

| Route | Page |
|---|---|
| `/` | Home |
| `/about` | About |
| `/work/huddle` | Huddle |
| `/work/wider-perspective` | Wider Perspective |
| `/governing-charter` | Governing Charter |
| `/contact` | Contact (WhatsApp, email, socials) — copy in `content/contact.ts` |

Qualification, FAQ and Operating Philosophy are popups.
`/governing-charter` reads its 16 sections from `content/charter.ts`.

## Scrolling and header

- Lenis smooth scrolling runs site-wide (`components/site/SmoothScroll.tsx`), off for reduced-motion users.
- The header scrolls away with the page, like the Framer site. To pin it, set `STICKY_HEADER = true` in `components/site/Header.tsx`.
- The round HOME button (bottom right, every page) always leads to the homepage hero.

## Editing content (no layout code needed)

- `content/site.ts` — menu, hero images, Why, Qualification, FAQ, Operating Philosophy, footer
- `content/events.ts` — **every session**. The When carousel and the month calendar both read this one list
- `content/practices.ts` — the What section: speakers, four functions, leaders, pricing
- `content/previously.ts` — Previously at Privé cards and their photo galleries
- `content/pages.ts` — About, Huddle, Wider Perspective copy and images

Image fields left as `""` show a neutral block (labelled in dev) until you paste a link.

## Black overlay on heroes

One setting in `app/globals.css`: `--hero-overlay` (black gradient, 0% at the top to 45% at the bottom).

## Fonts

Inter is bundled. Mencken Std (regular + bold) and Mencken Std Head (italic only, as supplied)
are self-hosted from `app/fonts/` via `next/font/local` (`app/fonts.ts`).

## SEO

- Titles, descriptions, canonical URLs and OG images per page: `lib/seo.ts` + each page's `metadata`
- Set `NEXT_PUBLIC_SITE_URL` if the live domain isn't https://theprive.network
- Favicon: `app/icon.png` (+ `app/apple-icon.png`)
- Unknown URLs show `app/not-found.tsx` with a button back to the homepage
- `/sitemap.xml` and `/robots.txt` are generated by `app/sitemap.ts` and `app/robots.ts` (add new pages to the sitemap list)
- Organisation structured data (name, address, LinkedIn/YouTube) is in `ORG_LD` in `lib/seo.ts`
- Old Framer addresses (`/home`, `/home/...`) redirect permanently in `next.config.ts`

## Shareable links

- `/?event=get-unstuck` opens that card's popup in the When carousel
- `/?session=oded-netzer` opens that session on the month calendar
- `/#calendar` scrolls to the calendar (the Calendar button uses this from other pages)
